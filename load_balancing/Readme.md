## Tahap pertama dalam membangun sistem terdistribusi ini adalah pengembangan aplikasi web sebagai backend service utama. Dalam modul ini, aplikasi dibangun menggunakan framework Blacksheep dengan pola arsitektur MVC (Model-View-Controller) untuk menyediakan endpoint dasar yang siap menerima permintaan . Secara fungsional, aplikasi ini berperan sebagai "pekerja" atau node yang bertugas memproses data dari pengguna, yang nantinya akan diperbanyak jumlahnya untuk menangani beban kerja. Dalam implementasi dunia nyata, langkah ini merepresentasikan pembuatan layanan spesifik atau microservice, seperti layanan login atau keranjang belanja pada aplikasi e-commerce, yang dirancang modular agar dapat dijalankan dan dikembangkan secara independen.
